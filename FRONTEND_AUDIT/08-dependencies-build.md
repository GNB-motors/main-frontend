# 08 — Dependencies & Build/Config

Scope: build config, bundle budget, lint posture, heavy/overlapping deps. (The **delete list** lives in [`09-unused-packages.md`](09-unused-packages.md).)

**Stack:** React 19.1 + Vite 7 + Tailwind 4 (via `@tailwindcss/vite`), react-router 7, vitest 2. No TypeScript (jsconfig + js/jsx). **No React Compiler.** Build = `npm run lint && npm run test && vite build && node scripts/check-bundle.mjs`.

**Correct by design (not flagged):**
- `@sentry/react` is async-loaded via `import('@sentry/react')` (`utils/sentry.js:184`) — kept out of the main chunk.
- `@base-ui/react` (14 files) is used only under `components/ui/` as the shadcn primitive layer (rule 16).
- Prod sourcemaps: none exposed (`vite.config.js` leaves `build.sourcemap` default false; `dist` has 0 `.map` files).
- `dist/` is **gitignored and not tracked** (`git ls-files dist` = 0) — the "committed dist" concern is unfounded.

## P1

### DEP-1 — Three live map / 3D-rendering stacks coexist
- **Priority:** P1 · **Effort:** L · **Confidence:** Confirmed
- **Evidence:** Leaflet (`RouteHub/routeHubMap.js`, 5 views); Google Maps (`@react-google-maps/api`, 21 files); deck.gl/three/loaders.gl (`RouteReplay/truck3d/Truck3DLayer.jsx` — a single file). Install footprint: `@loaders.gl` ~47 MB, `three` ~25 MB, `@deck.gl` ~12 MB (≈84 MB serving one 3D-truck file), `@react-google-maps` ~7.2 MB, `leaflet` present. `recharts` ~9.3 MB (8 files), `framer-motion` ~5.6 MB (2 files).
- **Root cause:** Features built incrementally on whichever map lib fit at the time; no consolidation pass.
- **Impact:** Large per-route lazy chunks (RouteReplay 3D and RouteHub Leaflet likely multi-MB each), tripled map-API maintenance surface, three sets of tiling/marker idioms. **The main-entry budget is unaffected (all lazy), so `check-bundle.mjs` never flags it** — a blind spot (DEP-5).
- **Fix:** Pick a strategy — Leaflet (free tiles) for 2D, Google only where Google-specific features are needed, gate the deck.gl/three 3D truck behind explicit opt-in. Each removed stack is multiple MB of lazy payload + one fewer idiom. (Removal mechanics in [`09-unused-packages.md`](09-unused-packages.md).)

## P2

### DEP-2 — Stale lint dumps committed to git
- **Priority:** P2 · **Effort:** S · **Confidence:** Confirmed
- **Files:** `frontend/lint_output.txt` (61 KB), `frontend/lint_report.json` (1.77 MB) — both `git ls-files`-tracked.
- **Evidence:** Dated Aug 11, UTF-16LE, contain hardcoded dev paths like `F:\gnb\frontend\main-frontend\frontend\src\...` and report `151 problems (131 errors, 20 warnings)` — a state that no longer exists (current lint = 0 errors). One-time dumps, not generated by any repo script.
- **Impact:** 1.8 MB stale cruft in history; leaks internal filesystem layout; misleads anyone reading them as current.
- **Fix:** `git rm` both and add to `.gitignore`.

### DEP-3 — 842 accessibility (jsx-a11y) warnings, all downgraded to `warn`
- **Priority:** P2 · **Effort:** L · **Confidence:** Confirmed
- **Files:** `eslint.config.js:61-64` maps all `jsxA11y.configs.recommended.rules` to `'warn'` ("Phase 7 remediates these").
- **Evidence:** Current `eslint .` — jsx-a11y total **842**: `control-has-associated-label` 505, `label-has-associated-control` 176, `click-events-have-key-events` 70, `no-static-element-interactions` 65, `no-noninteractive-element-interactions` 13, `no-autofocus` 10; plus `react/no-unescaped-entities` 31, `react-hooks/exhaustive-deps` 19.
- **Impact:** Real accessibility debt (unlabeled controls, `div onClick` without keyboard handlers — 42 clickable divs, conflicts with rules 17/18). Warnings never fail lint, so the count can only grow.
- **Fix:** Freeze with `--max-warnings 842` (ratchet down), then promote rules to `error` directory-by-directory as they're fixed.

### DEP-4 — `xlsx` static-import violates the project's own dynamic-import rule
- **Priority:** P2 · **Effort:** S · **Confidence:** Confirmed
- **Files:** Correct (dynamic): `lib/exportTable.js:106` `const XLSX = await import('xlsx')`. Violations (static): `utils/reportCsvExport.js:3`, `Drivers/BulkUploadDriversContent.jsx:2`, `Profile/BulkUploadVehiclesContent.jsx:2`.
- **Evidence:** `exportTable.js` documents a "Hard rule: xlsx is imported with a DYNAMIC import()." Yet `reportCsvExport.js` statically imports it and is pulled by 5+ lazy report routes. `xlsx` install ~7.2 MB.
- **Impact:** Main entry stays safe (consumers are lazy routes), but those report route chunks eagerly carry full `xlsx` (~400 KB+ min) on route entry instead of on export-click.
- **Fix:** Convert the 3 static importers to `await import('xlsx')` inside the export handler; add a `no-restricted-imports` rule for static `xlsx`.

### DEP-5 — Bundle budget only guards the main entry chunk
- **Priority:** P2 · **Effort:** M · **Confidence:** Confirmed
- **Files:** `scripts/check-bundle.mjs`, `vite.config.js`
- **Evidence:** `check-bundle.mjs` reads only the `index-*.js` referenced by `dist/index.html` (BUDGET 600_000). `vite.config.js` has **no** `build.rollupOptions.manualChunks` — splitting relies entirely on the 123 `React.lazy()` sites. No check on total payload or on the unbounded map/3D lazy chunks.
- **Impact:** The 600 KB main-chunk number is realistic and well-chosen, but gives false confidence — a route chunk can balloon to several MB (3D truck, Leaflet, recharts) with zero signal. No vendor `manualChunks` also means shared libs may duplicate across route chunks.
- **Fix:** Extend `check-bundle.mjs` to assert a ceiling on total `dist/assets` JS and on the largest individual chunk; consider `manualChunks` for shared vendor (react, recharts, maps).

## P3

### DEP-6 — React Compiler not enabled on React 19
- **Priority:** P3 · **Effort:** M · **Confidence:** Confirmed
- **Evidence:** `vite.config.js` plugins = `[react(), tailwindcss()]`; no `babel-plugin-react-compiler` in config or `package.json`.
- **Impact:** All memoization is manual — rules 7 and 3 exist precisely to manage that burden by hand (see [`01-performance.md`](01-performance.md)). The compiler would remove much of that rule surface and reduce re-renders.
- **Fix:** Evaluate `babel-plugin-react-compiler` in a branch; it pairs well with React 19 + the existing hooks lint.

### DEP-7 — Config hygiene (grouped)
- **Priority:** P3 · **Effort:** S · **Confidence:** Confirmed
- **Stale local `dist/`**: on disk from Sep 6 with `assets/index-zeqG649k.js` = 5,077,482 B (pre-split). Gitignored & untracked, but this 5 MB build would *fail* the current 600 KB budget if `check-bundle` ran against it. Harmless; `rm -rf dist`.
- **CSP is Report-Only**: `vercel.json` sets `Content-Security-Policy-Report-Only` — violations logged, not blocked. Promote to enforced once report noise is clean (ties to [`05-security-reliability.md`](05-security-reliability.md) SEC-2).
- **Two deploy targets**: `nginx.conf`/`Dockerfile.nginx` exist alongside `vercel.json` — ensure the `vercel.json` security headers are mirrored in `nginx.conf` if nginx is the prod path.

See [`09-unused-packages.md`](09-unused-packages.md) for `shadcn` (unused runtime dep), `cropperjs`/`react-cropper`, and the deck.gl/three removal analysis.
